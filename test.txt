## 数据源清单

### 考研数据
| 来源 | 用途 | 获取方式 | 更新频率 |
|---|---|---|---|
| 研招网专业目录 | 考试科目、招生人数 | 手工复制 | 每年9月 |
| 学校研究生院官网 | 学校线 | 手工复制 | 每年3月 |
| 学院官网复试通知 | 学院线 | 手工复制 | 每年3月 |

### 字段清单
| 字段 | 来源 | 是否必填 |
|---|---|---|
| 学校 | 所有来源 | 必填 |
| 学院 | 学院官网 | 必填 |
| 专业 | 研招网 | 必填 |
| 代码 | 研招网 | 必填 |
| 学位类型 | 研招网 | 必填 |
| 年份 | 所有来源 | 必填 |
| 总分 | 学校线/学院线 | 必填 |
| 政治/外语/数学/专业课 | 学校线/学院线 | 有则填 |
| 考试科目 | 研招网 | 有则填 |
| 招生人数/推免人数 | 研招网 | 有则填 |
| 学费/学制 | 研招网 | 有则填 |
| 数据来源 | 手工标注 | 必填 |

### 录入流程
1. 打开研招网/学院官网
2. 按字段清单逐项复制
3. 存入 CSV，检查逗号数量
4. 跑 csv_to_docs.py 验证
